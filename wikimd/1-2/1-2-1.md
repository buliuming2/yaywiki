# 豆芽人联盟的团队体系是什么？有哪些？
### 什么是团队体系
团队体系，又称团队阶级，是管理团队名号、资料、纪律的体系区分  
团队体系区分了每个成员的地位以及职务
### 团队体系有哪些？
豆芽人联盟团队体系分为4个，分别为五常、五下、星创委员会、普通成员，其中五常、五下、星创会分开讲
简略概括
| 体系名称 | 概括 | 权利 |
| ---- | ---- | ---- |
| 五常 | 豆芽人联盟五大最高权利成员，专门管理及运营联盟的一切 | 有一票否决权、主题确定权等 |
| 五下 | 五下，俗称“五常之下”，是仅次于五常的团队体系，可以和五常合作管理 | 有半票否决权、财务管理权等 |
| 星创委员会 | 专门负责简单管理和过渡作用，对新手友好，且加入其他体系保留原体系，新手加入活跃一段时间即可加入 | 核定权、成员组织权等 |
| 普通成员 | 只要是团队成员就默认带有普通成员体系 | 基础权利 |
